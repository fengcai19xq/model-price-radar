# 模型价格雷达 / Model Price Radar

一个 DeepSeek Harness Web UI 插件：实时读取各大模型的公开价格，处理峰时 / 谷时与上下文阶梯价，并按你的实际用量推荐当前最省钱的模型。

## 功能

- **实时价格**：从 OpenRouter 公开模型目录读取 400+ 个模型的输入、输出、缓存读写价格，每 2 分钟自动刷新，也可手动刷新。
- **分时计价**：解析数据源中的 UTC 星期与时段覆盖规则，自动计算当前是峰时、谷时还是标准价，并显示下一次调价倒计时。
- **详情弹窗**：点击模型即可查看所属厂家、模型擅长的方向、当前价、基础价、缓存读写、上下文、最大输出，以及本地时区的 24 小时价格带和时段列表；顶部提供该模型厂商的 **API 登录 / 注册入口**（无法识别厂商时回退到 OpenRouter 注册页）。
- **用量估算小工具**：默认按典型用量估算；点击右上角按钮打开弹窗，可用「轻量问答 / 客服机器人 / 代码助手 / 文档批处理」预设，或填写输入 / 输出 tokens、每日请求数、缓存命中率。
- **轻量筛选**：上下文下限、工具调用、图片输入、批量模型、免费 / 限速模型，收在排行上方的一行筛选条里。
- **自动加载**：排行每次先显示 20 条，滚动到列表底部自动加载下一批；也保留了「加载更多」按钮。
- **中英双语**：跟随 Harness 的语言设置。

## 使用

1. 在左侧栏底部点击雷达图标 **「模型价格雷达」**。
2. 「当前最优匹配」给出当前时段最省钱的模型；「省钱排行」可搜索、排序。
3. 点击任意模型行、最优卡片的「查看价格与分时」或右上角的分时模型，打开详情弹窗；弹窗内含该模型当前价 / 基础价 / 缓存价、24 小时价格带、时段列表，以及厂商 API 登录 / 注册入口。
4. 不熟悉 tokens 的用户可以点击右上角 **「用量估算」** 打开小工具，使用预设或填写每次请求规模；高级调整会立即更新排行和推荐。

## 价格口径

- 价格单位为 **USD / 100 万 tokens**，来源是 [OpenRouter Models API](https://openrouter.ai/api/v1/models)。
- 数据源将时段边界表示为 UTC `HHMM` 整数（例如 `100` = 01:00 UTC，`1600` = 16:00 UTC）。插件将其转换为本地时间显示。
- 支持两类额外定价：
  - `utc_days` / `utc_start` / `utc_end`：星期与时段覆盖。
  - `min_prompt_tokens`：上下文长度阶梯价。
- 估算日成本 = `输入 tokens × 输入价 + 缓存命中 tokens × 缓存命中价 + 输出 tokens × 输出价`，不包含缓存写入、搜索、图片等附加计费。
- 中国法定节假日可能影响供应商的实际计价，插件按数据源的星期规则计算，最终以供应商账单为准。
- 无固定价格的路由型模型（价格为负数）不会进入排行。

## 开发与验证

```bash
node --check client.js
TZ=Asia/Shanghai node test/pricing.test.mjs
TZ=Asia/Shanghai node test/render.test.mjs
```

测试覆盖：时段匹配、峰谷分类、下一次调价、24 小时时段切分、上下文阶梯价、成本估算、价格格式化、中英文字典键一致性，以及详情弹窗 / 用量估算弹窗的渲染冒烟。

## 文件

- `index.js`：Host 半边。比价在浏览器中直接请求 CORS 公开接口，Host 半边只提供 Loader 行。
- `client.js`：Client 半边，注册 `main` 面板与 `sidebar.panellist` 图标。
- `cordis.patch.yml`：向 profile 插入插件行。
- `locale/*.json`：插件管理器展示用标题和描述。
- `icon.svg`：原创雷达 + 价签图标。
